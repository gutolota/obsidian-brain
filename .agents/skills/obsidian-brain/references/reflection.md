# Reflection policy

Default window is 30 days with an equal preceding comparison window. Weekly review uses the last seven days.

Separate:
- deterministic counts: notes, tasks, completions, statuses, links;
- observed recurrence: repeated concepts supported by notes;
- interpretation: possible shifts or themes, labeled as hypotheses.

Every trend cites evidence. File mtime is only a proxy and must be disclosed. Ignore template boilerplate and generated reports when estimating themes. Absence of notes is not evidence of lost interest.
