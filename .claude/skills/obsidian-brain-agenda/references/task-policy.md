# Task policy

- A task stays in the note that provides its context; dashboards aggregate it.
- A literal unchecked checkbox is open; a checked checkbox is complete.
- Preserve Tasks-plugin dates, priority markers, recurrence, and completion dates.
- Do not turn vague wishes, examples, quotations, or third-party obligations into user tasks.
- Do not mark completion without an already checked source task or explicit user approval.
- Reports exclude `Templates/`, `.obsidian/`, and generated examples.
- Every reported task includes its source note link and original text.
