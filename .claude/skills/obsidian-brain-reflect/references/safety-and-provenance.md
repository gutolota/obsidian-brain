# Safety and provenance

## Automatic
Create reports, queues, dashboards, and new drafts. Fill missing metadata only when the user approved that operation.

## Approval required
Rename or move notes; change lifecycle states; merge or split notes; modify existing complete notes; add body links; infer tasks from vague prose.

## Never automatic
Delete raw notes; remove source body text; invent citations; present inference as fact; mark tasks done without evidence; run an unreviewed whole-vault rewrite.

Reports must state run time, scope, exclusions, deterministic counts, and semantic uncertainty. Generated files use a clear managed-file warning.
