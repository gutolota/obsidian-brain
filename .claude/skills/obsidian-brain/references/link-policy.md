# Link policy

Use: `supports`, `contradicts`, `extends`, `example_of`, `depends_on`, or `related`.

A recommended link needs:
1. inspected source and target notes;
2. a shared claim, question, dependency, example, or tension;
3. one-sentence justification;
4. confidence level.

Limit recommendations to five strong links per source note. Shared tokens, tags, author names, or project names can retrieve candidates but cannot justify a link alone. Apply links only after approval.
